# Sprudel

Klang's pattern language for live coding music. It provides a KlangEventSource that the KlangPlayer plays.

Sprudel started as a Kotlin implementation of [strudel.cc](https://strudel.cc). It no longer follows or mirrors
Strudel: for months now (as of 2026-10) it has diverged on purpose, in names, parameters and semantics. A
difference from Strudel is not a bug, and a Strudel name is not a reason to add an alias.
