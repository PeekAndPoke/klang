# Prototypes

Things tried out standalone, outside the build, before they are built into Klang for real (the maintainer,
2026-11-16). A prototype has a folder of its own with a README that says what it is, how to run it and which ticket
it belongs to. It goes when its port is done. Licensed like Klang (AGPL-3.0-or-later); nothing here is part of the
app, the engine or the tests.

| Prototype | What it is | Ticket |
|-----------|------------|--------|
| `band/` | A 3d band that plays Der Schmetterling: a plain three.js page | KLANG-00446 |
