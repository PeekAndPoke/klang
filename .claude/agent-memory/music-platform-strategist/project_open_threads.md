sequencing decided. Everything below is open, none of it is urgent, and none of it overrides the

## Threads left open, roughly in order of how alive they felt

1. **Track C tutorials are unwritten.** Ignitor, Master and Pipeline still have zero coverage. The most
   concrete gap in the current work.
2. **The two-sided launch gate is undefined.** "Stable and presentable" is Karsten's phrasing and it now
   clearly splits: *presentable for makers* = editor holds up, tutorial ladder reaches first sound fast;
   *presentable for listeners* = a catalogue exists at all. Nobody has written down what would make either
   true. Probably the highest-value strategic thread available.
3. **The "you still know how this goes" persona work.** The lapsed-musician finding
   ([[project_audience_sizing_metal_devs]]) has not yet been turned into actual positioning copy, and there is
   still no `personas.md` in `.claude/vision/`. A natural next artifact.
4. **Phase-pool blog post publish timing.** Draft exists; my view (in
   [[project_phase_pool_as_differentiator]]) is that it can publish *before* the gate as engineering writing,
   provided the "come and try it" call-to-action is held back.
5. **Is lo-fi a second founder lane?** Left explicitly open in the 2026-08-19 genre-lanes decision. It is
   arguably the least scene-fluency-dependent genre on the board.
6. **Hip-hop is the genuinely unserved opening.** Highest maker density, youngest cohort, no live-coding tool
   speaks to it, and beatmakers mostly do not code — so unlike electronic, its contributor search is *not*
   solved by the algorave overlap. Real gap, no plan.

## Decisions made 2026-08-19 (do not re-litigate, see `.claude/vision/decisions.md`)

Genre lanes: Karsten owns rock/metal/punk; techno is a **split lane** (90s flavour founder-reachable, modern
contributor-dependent); jazz, pop and classical are out for now, pop contingent on *recording* vocals (distinct
from the planned phoneme `sing()`). Flagship sequencing: metal → 90s techno → contributors. Eurodance is a
tutorial genre, not a flagship. Flagship-per-genre plus dissection tutorials is a **long-term** direction, basic
ladder first.
