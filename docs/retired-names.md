# Retired names

Every name this project removed, what replaced it, and where the decision is recorded. A retired name is never
restored and never cited as current (the rules register in `CLAUDE.md`). History keeps its words: diaries, archived
tasks and dated posts may still spell these names.

Moved here from `CLAUDE.md` on 2026-10-07 (the register stays short; this list is read when an old name turns up,
for example when porting an old song). Newest first.
