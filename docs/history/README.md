# Project history — quarterly summaries

Condensed, grouped-by-system summaries of what got built each quarter. Much shorter
than the running [DEV-DIARY](../../DEV-DIARY.MD) — read these for the shape of a
quarter, read the diary for the day-to-day.

| Quarter               | Span         | Theme                                                                |
|-----------------------|--------------|----------------------------------------------------------------------|
| [2025-Q4](2025-Q4.md) | Dec 2025     | Inception — oscillators, the strudel bridge, first synthesis         |
| [2026-Q1](2026-Q1.md) | Jan–Mar 2026 | KlangScript, the pattern language, the editor & web UI               |
| [2026-Q2](2026-Q2.md) | Apr–Jun 2026 | Making the engine *sound* good — warmth, the Engine DSL, performance |
| [2026-Q3](2026-Q3.md) | Jul to Sep 2026 | One shape for the engine: Katalyst, Ignitor trees, the V1 line |
| [2026-Q4](2026-Q4.md) | Oct to Dec 2026 | The frontend (editor, keys, the workbench); **plan:** Motor V1, tutorials, learning tools, the UI finished |
| [2027-Q1](2027-Q1.md) | Jan to Mar 2027 | **Plan:** the server's first steps; Motor V1.5 (side chains), V2's design (the configurable engine) |

New quarter file each quarter, same format. The first three months from inception
are covered by 2025-Q4 plus the early part of 2026-Q1.
