# 2027 Q1: Plan (Jan to Mar 2027)

> Forward-looking, a first outline from the Q4 planning with the maintainer (2026-10-28). Order and scope will
> drift; "sound first" still wins ties.

Two threads: Klang gets a server, and the Motor starts on its next version.

## The server: first steps (new)

Klang has run entirely in the browser so far. The drawer already shows two tiles waiting for it, "Community" and
"Account", "with the backend". What the first steps are is still open; to decide with the maintainer before the
quarter starts:

- accounts, and a user's songs kept on the server instead of in the browser;
- a song shared by a link;
- the look (KLANG-00376) and the key map (KLANG-00325) kept with the account instead of in the browser;
- the stack: the Ultra backend side, as in the maintainer's other projects.

Far beyond the first steps: federated song sharing (KLANG-00135).

## The Motor: V1.5, then V2

The Motor's versions (the maintainer, 2026-10-28; `docs/tasks/_v1-scope.md`):

- **V1.5: configurable side chains.** Ducking generalised: any signal drives any stage's knob (KLANG-00379).
  Ducking itself is built but never used (KLANG-00168).
- **V2: the fully configurable engine.** The engine as a signal graph (KLANG-00216), with the signal flow redesign
  (KLANG-00210) and the shared chain host (KLANG-00243); all in KLANG-00354 (the Motor's shape). Q1 is where its
  design starts; the build may run longer.

A new version may change how a song sounds. That is accepted while nobody but us has written music for Klang yet.
