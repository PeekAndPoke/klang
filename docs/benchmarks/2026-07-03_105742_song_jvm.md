# Song CPU Benchmark — JVM

- Runtime: `OpenJDK 64-Bit Server VM 17.0.17+10-LTS`
- Sample rate: 48000 Hz, block: 512 frames
- `medianRtf` = render/audio time (steady-state avg). `peakBlockRtf` = busiest single block (≈ worst render-cycle CPU).
- Lower is better. On JVM values are small; the browser worklet is ~10-30x slower, so multiply to relate to the 50%
  figure.
