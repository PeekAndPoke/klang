**The method.** Per case, the allocation check's own measurement (`AllocationCheck.kt`): two node processes,
`--trace-gc-nvp --max-semi-space-size=1 --min-semi-space-size=1`, `KLANG_ALLOC_WARM=20000`, then
`KLANG_ALLOC_COUNT` 0 or 200000; bytes per block = (window's summed `allocated=` minus base's) / 200,000; `NS` gives
the µs per block, `PEAK` the last block's peak.
- "`--predictable`, 1 process pair per case": the same with node's `--predictable` added (single-threaded, a
  deterministic compile history, so one pair per case).
- "the check's method (3 rounds)": without `--predictable`, three pairs, the median, as the check computes it.

**The runs.**
- **T**: the tree.
- **H**: HEAD's engine. Every `audio_be` production file the change touches put back to its HEAD content, the tree's
  `audio_benchmark` (so the same cases), inside one lock call, restored and compared.
- **Mutants** (each inside one lock call: the files backed up, the edit applied, the bundle relinked and copied, the
  files restored and compared with `cmp`, the tree's diff hash printed before and after; the copy measured):
  - **M1**: `KnobGlide.retarget` a plain method again (the `inline` removed).
  - **M6**: `KnobGlide`'s `value`, `target` and `start` back to three double fields.
  - **M7**: `Compressor.processGliding` takes its six ramp ends as arguments again (the `glideArgs` holder unused).
  - **M8**: `Phaser.process` calls `PhaserCore.prepareBlock(frames, centerTo, sweepTo)` with the two doubles again.
  - **G1**: every `isFiniteInline` of the chain's per-block hook back on the stdlib `isFinite()`: `KatalystSlots.kt`,
