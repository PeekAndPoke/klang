## Decide before implementing

- Which roles are edited directly and which are derived (an accent and its muted shade, the grain, the brushed finish).
- Where the editor lives: a tool window, a page of its own, or the drawer.
- Starting point: a copy of a built-in look, edited live, kept in the browser until there is an account (KLANG-00334 item 33).
- Sharing: export and import as text now, sharing through the server later (Q1 2027).
