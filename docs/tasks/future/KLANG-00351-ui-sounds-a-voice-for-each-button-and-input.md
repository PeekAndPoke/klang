# KLANG-00351: UI sounds: a voice for each button and input

> **Status (2026-10-27): IDEA.** for much later, the maintainer
>
> **Part of:** KLANG-00334 (UI workbench: the Motor-centred layout, tool windows and the first-visit trail)

## Why this exists

The maintainer, 2026-10-27: "Ohhhh and we need custom sounds for different button and inputs... but this is for
much later."

It fits the guiding idea of the UI epic (item 46, a machine made of tiles): a machine is heard as well as seen. A
key that clicks, a toggle that clacks into place, a knob with soft detents as it turns, the ignition key's turn, the
plate's rivets. The sounds would come from the Motor itself (sound first, and the engine is the horse: a UI sound is
a small patch played through the engine, not a separate sound system).

## Decide before implementing

- Which controls get a voice, and how quiet: a sound on every click tires fast; maybe only the mechanical ones (keys,
  toggles, knob detents, the ignition).
- Made with the Motor (Ignitor patches) or recorded samples, and in which orbit, so a playing song is not disturbed.
- A setting to turn them off (and off under `prefers-reduced-motion`? a separate preference is likelier).
- Whether a look (KLANG-00334's theme roles) brings its own sound set, as it brings its colours.
