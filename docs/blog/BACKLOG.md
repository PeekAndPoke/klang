## Notes for the writing skill (accumulating)

- Structure: problem (measured) → prior approaches with failure modes → bridge → method → results → open questions →
  numbered references. Paper skeleton, blog sentences.
- Verify every citation online before writing; mirror references into front matter YAML.
- Figures from real data wherever it exists; simulations clearly labeled as simulations.
- CommonMark/GFM only — no kramdown `{#id}`, no shortcodes; HTML anchors for reference items.
- Code blocks that *contain* markdown fences (KDoc with samples, nested markdown) need a **4-backtick outer fence**;
  never put backtick runs inside shorter inline code spans. Verify fence balance with a grep before calling a post done.
- **American English spelling** (center, color, behavior — never centre/colour/behaviour). User preference, applies to
  all prose.
- Tight figure hygiene: suptitle clearance, labels never over data, contrast tuned to the story the figure must tell
  (the Fig-1 lesson: 65 dB of honest dynamic range hid the point; 36 dB told it).
